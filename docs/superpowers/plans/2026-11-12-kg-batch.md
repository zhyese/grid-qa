# 知识图谱批量抽取实施记录

用户选择：多选文档、后台持久化执行、逐篇结果与失败重试；2026-11-12 要求开始实现。

## 设计与边界

复用 persistent_tasks 与 low 队列，一文档一任务，不新增服务或清理数据。
新增 KG 专属候选文档、提交、任务查询、重试接口，全部校验 kg:edit、租户、文档 ACL。
后台执行前重查提交人的账号状态、权限和文档授权。每批最多 200 个 ID，去重。
同文档活动任务复用，避免重复点击产生重复任务。原单篇入口保留并使用相同文档行锁。
客户端只提交一次，轮询任务；重进页面读取历史任务；每篇展示新增数、空结果、部分失败、失败原因。
模型调用全部失败必须报错，不能伪装成零条成功；部分失败保留成功分块并显示警告。
支持候选文档搜索、分页、选择当前页、选择当前页未建图项。

## 方案权衡

采用后台任务：避免 HTTP 60 秒超时，复用已有重试/心跳/重启恢复。
不采用前端逐篇请求：会碰到 5/minute 限流且离开页面中断。
不默认全库抽取：避免未经选择的大量模型费用。
