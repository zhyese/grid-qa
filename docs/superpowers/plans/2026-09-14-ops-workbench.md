# P0/P1 运维工作台实现计划

范围：规程变更影响分析、交接班、设备档案/复盘、遥测时序查询、表格精准查询。

## 验收边界

- 所有数据以登录用户租户隔离；文档派生结果在每次读取时重新检查 ACL。
- 新增独立 API 和页面，不改变原问答缓存语义；高级能力默认关闭。
- 变更分析：两个已解析文档按章节/顺序对齐，输出原文与数值变化；疑似关联不得声称为确定引用。
- 交接班：时间段快照含新增事件和未结束票据；草稿→交班审核→另一人接班确认，乐观锁保护并发。
- 设备档案：通过规范设备 ID 和已有主动运维关联汇总，不按模糊名称自动认定同一设备。
- 遥测：只接受带来源/质量/单位/时区的点数据，拒绝混合单位和重复冲突；计算在程序中完成，不推断因果，不伪造实时数据。
- 表格：复用 table chunk，通过列名+条件精确选行，返回完整行、表头、页码、分块证据；缺证据拒答。
- 测试：纯逻辑、数据库状态机、租户/ACL、API 权限、前端构建；部署受本机 Docker 可用性约束。

真实 SCADA 网关凭据、单位约定和生产数据由用户提供；本轮不实施设备控制、自动改票、自动发布规程。
